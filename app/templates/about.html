About vulnlocal

Version {{ version }} — offline CVE / Exploit-DB / MSRC correlator with Nmap NSE scanning and defensive detection templates.

What it is

vulnlocal mirrors official vulnerability intelligence locally so you can search CVEs, map exploits, Microsoft patches, generate YARA/Sigma hunting aids, and scan authorized hosts with the Nmap NSE script.

What it is not

  • Not a commercial GUI vulnerability-scanning product.
  • Not an exploit framework — Metasploit/Exploit-DB data is indexed for research correlation only.
  • Not a license to scan third-party systems. Use only on assets you own or are authorized to test.

Primary sources

  • CVE List V5 (CVE Project)
  • NVD JSON 2.0 feeds
  • Exploit-DB official Git archives
  • Microsoft Security Update Guide via MSRC CVRF API
  • CISA KEV, Nuclei templates, Metasploit modules, Nessus all-2.0.tar.gz metadata
  • CAPEC, Debian Security Tracker, Ubuntu CVE Tracker / SOSS / VCF (GitHub), OSV.dev, GitHub Advisories, PoC-in-GitHub, 0xMarcio/cve
