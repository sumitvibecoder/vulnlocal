Sync DB

Incremental sync: uses conditional HTTP (ETag / Last-Modified) and skips re-parsing when feeds are unchanged. Only changed bulletins are fetched from MSRC; NSE DB is re-exported only when something actually updated. First run or empty tables still do a full load.

Sync DB updates all feeds (including CAPEC, Debian, Ubuntu, OSV, GitHub Advisories, and PoC-in-GitHub). Extra advisories run early in the job. GitHub Advisories load the full github-reviewed set from the advisory-database zip (~34k; matches github.com/advisories).

Purge removes all ingested CVE / Exploit-DB / NVD / MSRC / feed rows from the live database (schema kept). A pre-purge backup is attempted first. Settings and download caches are not deleted.

Nmap scan downloads

Download Nmap NSE script Download NSE pack

Offline index is vulnlocal.pack/ (plain TSV buckets). The NSE Lua script reads it directly — no sqlite3 CLI. Online: nmap -sV --script vulnlocal --script-args vulnlocal.api=http://127.0.0.1:8088 <target> · Offline: nmap -sV --script vulnlocal --script-args "vulnlocal.db=/path/to/vulnlocal.pack" <target> Sync DB rebuilds nse/db/vulnlocal.pack (includes NVD CPE expansion for version matching).

Live status

Toggle Sync on/off per data source. Disabled sources are skipped on the next Sync DB / schedule run (local rows are kept). Exploit-DB prefers GitLab exploitdb; NVD uses official JSON 2.0 year + modified/recent zips (upsert, no duplicates). When CVEs is On, Sync also merges those NVD rows into the CVE table. Turn a source Off to skip it on Sync DB.
