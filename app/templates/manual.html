Manual

How to install, sync, search, and scan with vulnlocal {{ version }}.

1. Install

Supported on Windows, Linux, and macOS (Python 3.10+).

cd vulnlocal
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
python -m pip install -r requirements.txt
python run.py init-db
python run.py --host 127.0.0.1 --port 8088

Open http://127.0.0.1:8088. On Linux use python3 if python is unavailable. Dev mode: python run.py --dev.

2. Sync intelligence

  1. Optional: place a licensed all-2.0.tar.gz at the project root (or set path/URL in Settings).
  2. Optional: configure HTTP/SOCKS proxy in Settings.
  3. On Manage, click Sync DB. This updates Exploit-DB, CVE delta, NVD, CWE, CISA KEV, Nuclei, Metasploit, plugin metadata, and the full MSRC Update Guide CVRF set.

3. Search & CVE pages

Use Home search for CVE IDs, products, or exploit titles. CVE pages show severity, patches, Exploit-DB, MSRC KBs, plugin maps, Nuclei/Metasploit hits, YARA/Sigma templates, ATT&CK heuristics, and a unified References list.

4. Scan with Nmap NSE

Host assessment is done with the vulnlocal NSE script (service detection + offline/online correlation). Download the package from Manage. Offline mode uses vulnlocal.pack/ (plain TSV) — the NSE Lua script reads it directly with no sqlite3 CLI.

Place the script under:

  • Linux: /usr/share/nmap/scripts/vulnlocal/
  • Windows: C:\Program Files (x86)\Nmap\scripts\vulnlocal\
nmap --script-updatedb
nmap -sV --script vulnlocal/vulnlocal \
  --script-args "vulnlocal.db=/path/to/vulnlocal.pack" <authorized-target>

Windows path example (forward slashes):

nmap -sV --script vulnlocal/vulnlocal --script-args "vulnlocal.db=D:/path/to/vulnlocal.pack" <authorized-target>

Or use online mode against your running app (http or https):

nmap -sV --script vulnlocal/vulnlocal \
  --script-args vulnlocal.api=http://127.0.0.1:8088 <authorized-target>

5. Backup & restore

On Manage, use Backup & restore to snapshot the local SQLite DB into data/backups/ (optionally with settings.json). Restore from a listed backup or upload a .db/.zip. Stop Sync before restoring; a pre-restore snapshot is written automatically.

6. CLI helpers

  • python run.py ingest-all — full local load
  • python run.py sync-cve — CVE delta only
  • python run.py package-nmap / package-db — release artifacts
