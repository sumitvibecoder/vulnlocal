FAQ

Common questions about vulnlocal {{ version }}.

How do I scan hosts for vulnerabilities?

Use the vulnlocal NSE script with Nmap. It detects services (-sV) and correlates versions against the offline vulnlocal.pack index (or the local web API). Download the NSE package from Manage. Offline mode needs no sqlite3 CLI — Lua reads the pack directly.

Is the offline database encrypted?

No. The NSE offline index is a plaintext vulnlocal.pack/ directory (TSV buckets) so Lua can read it with no helper binary. The app DB under data/ is plaintext SQLite for search/UI.

What are the YARA / Sigma rules on CVE pages?

Heuristic detection templates for blue teams: YARA for EDR file/memory hunting, Sigma for SIEM correlation. They are generated from local CVE / Exploit-DB / Metasploit metadata and must be tuned before production.

Where does Microsoft patch data come from?

From the official MSRC CVRF API (swagger) that powers the Security Update Guide — including year indexes, monthly cvrf/{yyyy-Mmm} documents, optional CSAF equivalents, and the Update Guide RSS for recent changes. Sync DB stores bulletin years offline in SQLite (not HTML scrape). The Guide lists Microsoft Security Update Guide CVEs (monthly Patch Tuesday + out-of-band), not every CVE ever published by MITRE. Home shows the latest monthly Patch Tuesday set with Publicly disclosed / Exploited Yes/No from MSRC threat metadata.

How do I keep data current?

Open Manage → Sync DB. Configure proxy and source URLs under Settings if needed.

Does the app crawl Exploit-DB or CVE.org pages?

No. It uses official bulk archives / JSON APIs only.
