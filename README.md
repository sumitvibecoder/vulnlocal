# vulnlocal

**Offline CVE · Exploit-DB · NVD · Microsoft MSRC correlator** with a local web UI, Patch Tuesday view, KB mapping, YARA/Sigma aids, and Nmap NSE scanning.

Mirrors **official** bulk/JSON feeds only (no HTML scraping). For authorized research on systems you own or have permission to test.

## Important limitations

| Claim | Reality |
|---|---|
| Commercial GUI vuln scanner | **No** — host scanning is Nmap NSE + local DB |
| Scrapes MSRC Update Guide HTML | **No** — official MSRC CVRF API |
| Exploit runner | **No** — research correlation only |

## Features

- Home search + Latest CVEs / Latest exploits + Microsoft Patch Tuesday
- CVE detail (patches, EDB, MSRC KBs, plugins, Nuclei/MSF, YARA/Sigma, ATT&CK, References)
- Manage — Sync DB, backups, purge, NSE package download
- Settings — proxy and feed URLs
- Offline **slim plaintext** NSE SQLite DB (CVE id + vulnerability name + product/CPE; queried from Lua via `sqlite3` CLI)
- Extra feeds: CAPEC, Debian tracker, Ubuntu CVE Tracker / SOSS / VCF, OSV, GitHub Advisories, PoC-in-GitHub / 0xMarcio/cve

## Quick start

Works on **Windows**, **Linux**, and **macOS** (Python 3.10+).

```bash
git clone https://github.com/<your-org>/vulnlocal.git
cd vulnlocal
python -m venv .venv
# Windows (cmd):  .venv\Scripts\activate
# Windows (PowerShell):  .venv\Scripts\Activate.ps1
# Linux/macOS:  source .venv/bin/activate
python -m pip install -r requirements.txt
python run.py init-db

# Full sync via UI: Manage → Sync DB
# or: python run.py ingest-all

python run.py --host 127.0.0.1 --port 8088
# development (debug + reloader; loopback only):
# python run.py --dev --host 127.0.0.1 --port 8088
```

On Linux, if `python` is not found, use `python3` instead.

Open http://127.0.0.1:8088

### Offline Nmap (Windows / Linux)

1. Install Nmap and the `sqlite3` CLI (`sqlite3.exe` on Windows, `sqlite3` package on Linux).
2. Download the NSE script + DB from Manage (or copy from this repo’s `nse/` folder).
3. Install under Nmap’s scripts directory as a `vulnlocal/` package:

```text
Source (in this repo):  vulnlocal/nse/vulnlocal.nse  +  vulnlocal/nse/db/
Install to:
  Linux:   /usr/share/nmap/scripts/vulnlocal/
  Windows: C:\Program Files (x86)\Nmap\scripts\vulnlocal\
```

```bash
nmap --script-updatedb
nmap -sV --script vulnlocal/vulnlocal \
  --script-args vulnlocal.db=/path/to/vulnlocal.db <authorized-target>
```

Windows example:

```text
nmap -sV --script vulnlocal/vulnlocal --script-args vulnlocal.db=C:\path\to\vulnlocal.db <authorized-target>
```

## Repository layout (what to push)

Upload / push only the **`vulnlocal/`** project root (this folder), not the parent `nmapscripts` tree.

```text
vulnlocal/
  app/                 # Flask app, ingest, sync, export
  nse/
    vulnlocal.nse      # NSE script (committed)
    db/.gitkeep        # offline DB is local-only (gitignored)
  static/  templates/
  run.py  requirements.txt
  README.md  LICENSE  SECURITY.md  CREDITS.md  CHANGELOG.md
  data/.gitkeep        # SQLite + settings stay local
  downloads/.gitkeep   # feed caches stay local
```

Before the first push:

```bash
python run.py prepare-repo
```

That deletes download zips, CVE extract trees, package/backup zips, `__pycache__`, and leftover NSE temps. Your local `data/vulnlocal.db` is **kept** but gitignored.

### What not to commit

`.gitignore` already excludes:

- `data/**` (SQLite DB, backups, extracts) — folder kept via `.gitkeep`
- `downloads/**` (feed caches / large zips)
- `nse/db/*.db` (regenerated by Sync / export-nse)
- `settings.json`, `.env`, `__pycache__`, `*.zip`

## Nmap (offline)

After Sync, download the NSE script + plaintext DB from Manage. Offline mode needs the `sqlite3` CLI on PATH.

```bash
nmap -sV --script vulnlocal/vulnlocal \
  --script-args vulnlocal.db=/path/to/vulnlocal.db <authorized-target>
```

Online against the local app:

```bash
nmap -sV --script vulnlocal/vulnlocal \
  --script-args vulnlocal.api=http://127.0.0.1:8088 <authorized-target>
```
